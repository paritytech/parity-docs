# Polkadot Network Resources

## Introduction

These docs cover software that Parity writes. Pages about the Polkadot network itself, such as live deployments, network parameters, governance, staking, and ecosystem tools, are maintained by the Polkadot Community Foundation in the [Polkadot Developer Docs](https://developers.polkadot.com/). They used to live on this site, and their old URLs redirect to the same paths there.

This page maps every moved page to its new location, grouped by topic. For the software these docs do cover, see [What Parity Builds](/get-started/index.md).
